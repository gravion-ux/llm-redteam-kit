# llm-redteam-kit Pro

The free core of llm-redteam-kit stays free and complete: the core probe
pack, the CLI, mock runs, and CI gating all work without payment.

Pro exists for teams that run the kit as a recurring CI gate and want the
maintained content and support around it.

| Capability | Free | Pro |
|---|---|---|
| Core probe pack (`packs/core.jsonl`) | Included | Included |
| CLI, mock runs, threshold gating | Included | Included |
| Expanded, maintained probe packs | — | Included |
| Baseline management across runs | — | Included |
| Priority support | — | Included |
